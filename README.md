# WebM to MP4 for Premiere

A small Windows desktop app that converts WebM videos to MP4 for editing in Adobe Premiere Pro.

## Download

Download **WebMToMP4-Windows-v1.zip** from the [latest release](../../releases/latest), extract it, and run `WebM to MP4.exe`.

## Requirements

- Windows 10 or later
- FFmpeg installed separately and available to the app
- NVIDIA GPU is optional; the app can use NVENC when available and otherwise falls back to CPU encoding

This repository contains the packaged download only. The Python source is kept in a separate private repository.
